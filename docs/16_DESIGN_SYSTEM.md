# JobAllocate Design System & Tokens Specification

> **Document Version:** 1.0.0
> **Source:** `lib/constants/app_colors.dart`

---

## 1. Color Tokens

| Token Name | Hex Code | Visual Usage |
|---|---|---|
| `Primary` | `#174A7E` | JobAllocate Brand Blue, Header Background, Primary Buttons |
| `Primary Dark` | `#0F2C4D` | Dark Accents, Footer Background |
| `Secondary / Accent` | `#0284C7` / `#38BDF8` | Highlights, Sky Blue Badges |
| `Alert / Danger` | `#E53E3E` / `#EF4444` | Rejection Badges, Urgent Tags |
| `Success` | `#16A34A` / `#22C55E` | Shortlisted Badges, Verified GST Badges |
| `Background Light` | `#F8FAFC` | Main Page Background |
| `Surface` | `#FFFFFF` | Card & Form Modal Background |

---

## 2. Typography & Fonts
- **Font Family**: Google Fonts — **Plus Jakarta Sans** (fallback `system-ui`, `sans-serif`).
- **Headings**: `font-extrabold` / `font-bold` tracking-tight.
